
# Market % Label Wording Options

Goal: add a descriptive label next to the `%` value in Market rows, while keeping sort based only on numeric `%`.

## 1) Recommended
- `< -5%`: `Discounted`
- `-5% to +5%`: `Market Average`
- `> +5%`: `Premium`

Why: neutral language that still helps both buying and selling decisions.

## 2) Player-Friendly
- `< -5%`: `Great Buy`
- `-5% to +5%`: `Fair Price`
- `> +5%`: `Strong Sell`

Why: very clear action cues, but more opinionated.

## 3) Trader Tone
- `< -5%`: `Below Avg`
- `-5% to +5%`: `Near Avg`
- `> +5%`: `Above Avg`

Why: concise and factual, but less readable for casual players.
