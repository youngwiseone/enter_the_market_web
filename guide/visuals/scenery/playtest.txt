Weather wallpaper and energy-driven farm banner — 2026-10-07

Desktop wallpaper is now a separate Windows 98 inspired pixel lake scene.
Rain uses an overcast scene with visible shoreline puddles and ripple rings.
The banner uses one five-row sprite sheet: morning, midday, afternoon,
evening and night. A small text label makes its state unambiguous.
The existing persisted dayEnergySpent drives visual progress, with the energy
deficit as a legacy fallback; zero energy always shows night. Rest resets
the day counter. No save schema or gameplay rules changed.
Rain applies a static local rain layer to the banner; no animation loop,
particles, timers or new libraries. The farm interface is no longer dimmed
as a whole, so crop and control contrast stays readable at night.
